# zapret (nfqws) upgrade for Padavan

- `padavan/integrate.sh` — run from `pre-build.sh`: nfqws 71.4 → 72.13
  (vendored source, sha256-checked), firmware patch rebased onto 72.13,
  new strategy profiles and their names in the web UI.
- `strategies/` — `strategy` (default) and `strategy0..9`, generated by
  `tools/flowseal2nfqws.py` from
  [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)
  (MIT). Each has QUIC/YouTube, YouTube TCP, Discord (UDP + media), general
  TCP on the user hostlist, and a Telegram calls block (STUN, UDP 590-1400,
  3478-3481). All validated with `nfqws --dry-run` 72.13.

Regenerate after a Flowseal update:

    git clone --depth 1 https://github.com/Flowseal/zapret-discord-youtube
    python3 zapret/tools/flowseal2nfqws.py zapret-discord-youtube zapret/strategies

Profiles are copied to `/etc/storage/zapret` only where a file is absent, so
a router that already has them keeps its own; to take the new ones:
`rm /etc/storage/zapret/strategy*; mtd_storage.sh save`, then restart zapret.
